## Start here

📋 **[BRAND-STRATEGY.md](BRAND-STRATEGY.md)** — the master plan: mission, positioning,
channels, SEO standards, and the 5–10 year roadmap. Everything else serves this document.

## Structure

| Path | What it is |
|---|---|

| `brand/professional-identity.md` | Canonical identity, naming rules, NAP consistency checklist, tone of voice |
| `brand/biography.md` | Bio drafts (short/medium/long) + speaker profile + info checklist for Saja |
| `content/content-calendar.md` | 90-day publishing plan |
| `content/articles/` | Pillar articles, each with a full SEO package ready to publish |
| `docs/` | The website — plain HTML with schema.org markup, GitHub Pages–ready |

## Publishing the website

1. In the GitHub repo settings, enable **Pages** → deploy from branch → `/docs` folder.
2. When a custom domain is confirmed, update the canonical URL, `og:url`,
   `docs/robots.txt`, and `docs/sitemap.xml`.
3. Verify the site in Google Search Console and submit the sitemap.

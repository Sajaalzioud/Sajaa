## LOGO SPECIFICATIONS & CLEAR SPACE

### Clear Space Guidelines
**Minimum Clear Space**: Equals the height of the logo mark

```
┌─────────────────────────────────────┐
│ ↕ (Clear Space) = Logo Mark Height │
│  ┌─────────────────┐                 │
│  │   Logo Mark     │                 │
│  └─────────────────┘                 │
│ ↕ (Clear Space) = Logo Mark Height │
└─────────────────────────────────────┘
```

### Minimum Size Requirements

**Print Applications**:
- Logo + Wordmark: Minimum 1.5 inches wide
- Logo Mark Only: Minimum 1 inch wide
- Business Card: 1 inch width minimum
- Letterhead: 1.5 inches width minimum

**Digital Applications**:
- Web Header: 200px - 300px width
- Mobile App Icon: 192px - 512px
- Social Media: 200px - 1200px
- Favicon: 32px - 64px
- Website Footer: 80px - 120px

## LOGO APPLICATIONS & LAYOUTS

### Horizontal Layout (Logo + Wordmark)
**Best For**:
- Website headers
- Email signatures
- Letterhead
- Print materials
- Social media headers
- Large signage

**Proportions**:
- Mark to Text Ratio: 1:1.5
- Spacing: 20-30px between mark and wordmark
- Overall Height: 1.5-3 inches (print), 120-300px (digital)

---

### Stacked Layout (Mark Over Wordmark)
**Best For**:
- Social media profiles (circular layouts)
- App icons
- Building signage (vertical spaces)
- Uniforms and badges
- Limited width applications

**Proportions**:
- Mark Width: 100% of total width
- Text Width: 110% of mark width
- Vertical Spacing: 15-20px between mark and wordmark
- Overall Height: 2-4 inches (print), 150-400px (digital)

---

### Icon Only (Mark Alone)
**Best For**:
- App icons (all sizes)
- Favicon
- Social media profile pictures
- Small signage
- Watermarks
- Embroidered logos

**Specifications**:
- Square Format: 1:1 aspect ratio
- Minimum Size: 32px digital, 0.5 inches print
- No text accompany
- Works in all color modes

## LOGO COLOR VARIATIONS

### Full Color
**Primary Application**: Digital screens, color print materials
**Use When**: Brand positioning requires maximum visual impact and color communication

### Monochrome - Black
**Primary Application**: Single-color print, low-cost printing, faxes, documents
**Use When**: Cost-effective printing or black/white reproduction required
**Specification**: Solid black (#000000) or match printer black

### Monochrome - White
**Primary Application**: Reverse applications (dark backgrounds, signage)
**Use When**: Applied to dark or branded color backgrounds
**Specification**: Solid white (#FFFFFF) with appropriate contrast

### Monochrome - Grayscale
**Primary Application**: Newspaper, black & white photography
**Use When**: Printed in grayscale format
**Specification**: Gradient grayscale from light to dark tones

## DO's AND DON'Ts

### ✓ DO

✓ **Maintain Proportions**: Always scale proportionally - never distort
✓ **Preserve Clear Space**: Always maintain minimum clear space
✓ **Use Approved Colors**: Only use colors from official palette
✓ **Protect Legibility**: Never use logo smaller than minimum size
✓ **Check Contrast**: Ensure sufficient contrast on backgrounds
✓ **Respect Orientation**: Maintain primary logo orientation
✓ **Use High Resolution**: Always use vector files (SVG) or high-res (300 DPI) exports
✓ **Get Approval**: Seek approval for new applications

---

### ✗ DON'T

✗ **Don't Distort**: Never rotate, skew, or stretch the logo
✗ **Don't Add Effects**: No unauthorized shadows, glows, or 3D effects
✗ **Don't Change Colors**: Don't use unauthorized color combinations
✗ **Don't Outline Text**: Don't add strokes or outlines to typography
✗ **Don't Reverse Unexpectedly**: Ensure proper contrast if reversing colors
✗ **Don't Place on Clashing Patterns**: Avoid busy backgrounds that reduce legibility
✗ **Don't Use Low Resolution**: Never use pixelated or low-resolution versions
✗ **Don't Create Knockoffs**: Never create similar logos to avoid confusion

## FILE FORMATS & DELIVERABLES

### Source Files
- **SVG** (Scalable Vector Graphics) - Fully editable, infinite resolution
- **AI** (Adobe Illustrator) - Professional design file
- **PDF** - Universal vector format for printing

### Export Formats

#### Web/Digital
- **PNG** - Transparent background, RGB color mode
  - 72 DPI for web
  - All variations (full color, black, white)
  - All sizes (32px to 2000px)

- **SVG** - Vector format for web scalability
  - All variations included
  - Optimized for web

- **WebP** - Modern web format
  - Smaller file size than PNG
  - All color variations

#### Print
- **PDF** - Vector format
  - All color specifications
  - CMYK color mode
  - 300 DPI

- **EPS** - Professional print format
  - All variations
  - CMYK color mode
  - Compatible with professional printers

- **TIFF** - High-resolution raster
  - 300 DPI minimum
  - CMYK color mode
  - All variations

#### Social Media
- **PNG** - Transparent, all sizes
  - Profile: 400x400px
  - Cover: 1200x630px
  - Posts: 1080x1080px

## File Formats

All mockup files are provided as **SVG (Scalable Vector Graphics)**:
- Infinitely scalable without quality loss
- Fully editable in design software
- Crisp rendering at any size
- Professional print-ready quality
- Small file sizes for easy sharing

### Export Options
Each mockup can be exported to:
- **PDF** - Print-ready professional format
- **PNG** - Web-ready raster format (72 DPI for web, 300 DPI for print)
- **JPG** - Compressed format for email sharing
- **EPS** - Adobe Illustrator format for further editing

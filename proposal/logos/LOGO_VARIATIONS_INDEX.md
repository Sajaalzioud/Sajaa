## File Format Overview

### Current Formats
All files are provided as **SVG (Scalable Vector Graphics)** which means:
- ✅ Infinitely scalable without quality loss
- ✅ Fully editable in design software (Adobe Illustrator, Figma, Inkscape)
- ✅ Crisp rendering at any size from 32px to 10,000px
- ✅ Smaller file sizes than raster formats
- ✅ Perfect for professional printing and digital display

### Size Specifications

#### Mark Files (300x300px viewBox)
- Suitable for scaling to 32px - 2000px without loss of quality
- Ideal for: app icons, favicons, digital badges, social media profiles

#### Layout Files (900x300px or 1200x300px viewBox)
- Horizontal layouts: 900x300px
- Bilingual layouts: 1200x300px
- Suitable for: website headers, business cards, email signatures, social media

#### Stack Layout Files (400x600px viewBox)
- Vertical stacked arrangements
- Suitable for: vertical applications, mobile displays, social media stories

## Naming Convention

All files follow a consistent naming pattern:
```
C[Concept]_[LayoutType]_[LanguageVariant].svg
```

**Components:**
- `C1/C2/C3` = Concept number (1, 2, or 3)
- `mark` = Logo mark only
- `icon_only` = Icon-only square format
- `horizontal_layout` = Horizontal arrangement
- `stacked_layout` = Vertical stacking
- `bilingual_horizontal` = English + Arabic side-by-side
- (optional) `black/white/full_color` = Color variation for marks
- (optional) `arabic` = Arabic language version

**Examples:**
- `C1_mark_full_color.svg` = Concept 1, mark, full color
- `C2_horizontal_layout_arabic.svg` = Concept 2, horizontal, Arabic version
- `C3_bilingual_horizontal.svg` = Concept 3, bilingual layout

## How to Use These Files

### For Web Applications
1. Use SVG files directly in HTML (`<img>`, `<svg>`, or CSS background)
2. Use 72 DPI PNG for fallback support
3. Ensure proper scaling with CSS media queries

### For Print Applications
1. Export SVG to PDF using design software
2. Use 300 DPI PNG for raster inclusion
3. Reference COMPREHENSIVE_BRAND_GUIDELINES.md for clear space and sizing

### For Mockups and Presentations
1. Import SVG files into design software
2. Scale appropriately for application context
3. Apply to realistic contexts following brand guidelines

### For Digital Marketing
1. Optimize SVG for web (remove unnecessary attributes)
2. Use icon-only versions for social media profiles
3. Use horizontal layouts for header graphics
4. Reference bilingual versions for diverse audiences
